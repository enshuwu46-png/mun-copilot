服务说明与隐私边界

服务说明

本工具用于学习训练、写作修改、模联资料整理和表达练习。生成内容应作为草稿、讲解或参考，不应直接用于作弊、代写、冒充原创或规避学校要求。

付费套餐按每日额度和额外次数计量。真实支付到账后系统自动开通套餐；人工收款需要管理员在后台确认。

隐私边界

账号邮箱、订单状态、额度、生成记录会保存在服务器数据文件中，用于登录、扣额度、售后和运营统计。不要输入身份证号、银行卡号、住址等敏感个人信息。

API Key、支付密钥和后台密钥只应配置在服务器环境变量中，不会放到前端页面或 GitHub 仓库。
